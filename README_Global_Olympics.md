# Global Olympics Dashboard – Tableau

## Project Overview
An interactive Tableau dashboard exploring Olympic data, medal distribution, sports performance, and athlete statistics.

## Tools Used
- Tableau Public
- CSV dataset

## Dashboard Features
- Total Athletes KPI
- Total Medals KPI
- Gold Medals by Region
- Medals by Sports
- Sports Performance Treemap
- Medal Distribution Pie Chart

## Live Dashboard
[View the dashboard on Tableau Public](https://public.tableau.com/app/profile/prachi.upadhyay4510/viz/globalolynpicsdasbord2026/Dashboard1)
